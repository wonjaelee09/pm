# Career AI Transition Tracker App

Static dashboard for Jake's career scoreboard and Kanban.

## Local use

Open `index.html` directly, or serve it:

```bash
cd /opt/data/projects/career-ai-transition/app
python3 -m http.server 8095
```

Then visit `http://127.0.0.1:8095` from inside the same environment.

## Deployment

This is Vercel/GitHub Pages-ready static HTML. Stable public deployment requires repo/hosting credentials.
